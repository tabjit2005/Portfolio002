เว็บรวมผลงานที่ส่งอาจารย์ (GitHub Pages)

## วิธีขึ้นเว็บ
1. สร้าง repo ใหม่บน GitHub ชื่อ **`tabjit2005.github.io`** (Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `works/`) ไปที่ branch `main`
3. ไปที่ Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`
4. รอประมาณ 1 นาที แล้วเปิด https://tabjit2005.github.io/
